# Icons

Pack: **Lucide** via `lucide-static` v1.77.0 (ISC licence, see `LICENSE`).

- `svg/` holds the original files, copied unmodified from the npm package.
- `sprite.svg` is generated from `svg/` (each file becomes `<symbol id="icon-NAME">`). Reference icons as `<svg class="icon" aria-hidden="true"><use href="assets/icons/sprite.svg#icon-NAME"></use></svg>`.
